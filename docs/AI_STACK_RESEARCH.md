## 4. 이미지 처리 AI 조사 결과

### 4-1. Gemini - 사용자 선택

| 기능 | Gemini 가능 여부 | 비고 |
|------|----------------|------|
| 화질 복원 (enhance) | 가능 | Gemini 2.0 Flash 이미지 편집 |
| 흑백→컬러 변환 | 가능 | 프롬프트 기반 컬러화 |
| 오래된 사진 복원 | 가능 | 손상 복원 |
| 배경 제거 | **불가** | 투명 PNG 출력 미지원 |
| 영정사진 생성 (정장 합성) | 조건부 가능 | 얼굴 보존 안정성 문제 보고 있음 |
| 일상복 사진 생성 | 조건부 가능 | 동일 얼굴 보존이 핵심 과제 |
| 반려동물 AI 초상화 | 가능 | 수채화/유화/만화 스타일 |

**조사에서 확인된 Gemini 한계점** (참고용):
- `투명 배경 PNG 출력 불가` - 배경 제거 기능에 직접 사용 불가
- `얼굴 보존(face consistency)` - 복잡한 옷 스타일 변경 시 얼굴이 달라지는 사례 보고
- 정확한 face-swap 수준의 동일인 보장은 어려움

### [결정 1] 배경 제거 (remove-bg) 구현 방법

Gemini는 투명 PNG 출력이 불가능하므로 배경 제거는 별도 처리가 필요합니다.

**옵션 1-A** - `remove.bg API` 유지  
- 투명 PNG 완벽 지원  
- 비용: $0.05/이미지  
- 기존 PRD 계획과 동일  

**옵션 1-B** - `rembg` 오픈소스 Python 서버 자체 운영  
- 무료 (서버 비용만 발생)  
- Python 워커 별도 구축 필요  
- 응답 속도 자체 서버에 의존  

**옵션 1-C** - `Gemini`로 통일 (배경 제거 기능 제외)  
- 배경 제거를 서비스 기능에서 제외하거나 흰 배경 교체 방식으로 대체  
- 구현 가장 단순

### [결정 2] 영정사진 생성 방식

업로드된 사진에서 정장 착용 영정사진을 만드는 방법입니다.

**옵션 2-A** - `Gemini 이미지 편집`만 사용  
- 프롬프트: "이 사람의 얼굴을 유지하면서 정장으로 교체해줘"  
- 비용: Gemini API 비용만  
- 리스크: 얼굴 불일치 발생 가능  

**옵션 2-B** - `FASHN.AI` (가상 착용 특화 API) 사용  
- 얼굴 보존하면서 옷만 교체하는 데 특화  
- 정장 이미지를 별도 준비해서 합성  
- 비용: FASHN.AI API 별도  

**옵션 2-C** - `Gemini` 배경 합성 + `remove.bg` 조합  
- remove.bg로 인물 누끼 → Gemini로 정장 배경 생성 → 합성  
- 두 API 조합  

**옵션 2-D** - 정장 합성 기능 제외, 단순 화질 개선만 제공  
- 서비스 범위를 줄이는 대신 구현 단순화

## 9. 영상 퀄리티 향상 전략 리서치 (2026-07-06)

### 핵심 결론

멀티 레퍼런스(사용자가 "9분할"이라 표현한 아이디어 — 같은 인물의 여러 각도/표정 이미지를 참조로 제공)는 "이미지 생성 단계의 identity 일관성"을 높이는 기법으로는 실제 검증됨(InstantID/PuLID 논문, Higgsfield "Soul ID" 기능 등). 하지만 온담이 실제로 겪는 문제인 "립싱크 영상 자체의 프레임 간 얼굴 흔들림(temporal consistency/face drift)"을 직접 해결하는 기법은 아니다 — 이는 별개의 모델 내부 아키텍처 문제(ConsistTalk 등 논문은 광류 기반 시간 모듈 등으로 해결).

### 벤더별 멀티 이미지 입력 지원 여부 (공식 문서 기준)

| 벤더 | 멀티 이미지 지원 | 비고 |
|------|-----------------|------|
| **Higgsfield** | 지원 (Soul ID, 20~80장) | 립싱크/talking-head 엔드포인트에 실제 연동되는지는 불확실 — 벤더 문의 필요 |
| **SadTalker (Replicate)** | 미지원 | 단일 `source_image`만 허용 |
| **Hedra** | 미지원으로 추정 | 명시적 미지원 문구는 확인 못함 |
| **HeyGen** | 핵심 talking-head 기능(Avatar IV)은 단일 사진만 사용 | "Photo Avatar Group"(10~15장)은 의상/포즈 변형용이지 얼굴 안정성 목적 아님 |
| **D-ID** | 미지원 | "단일 이미지로 충분"이라고 공식 명시 |

결론: 검토 중인 5개 벤더 중 실질적인 talking-head 파이프라인에서 멀티 이미지를 직접 지원하는 곳은 없음. 아이디어를 살리려면 "멀티 레퍼런스로 고품질 단일 정면 이미지를 먼저 합성 → 그 결과물 1장을 립싱크 벤더에 투입"하는 별도의 2단계 전처리 파이프라인이 필요하며, 이는 벤더 선택과 무관한 신규 기능 개발이다.

### 기타 실무 퀄리티 향상 기법

- **소스 사진 전처리**: HeyGen 공식 가이드가 명시적으로 권장 — 정면 각도, 균일한 조명, 중립 표정, 선글라스/모자·극단적 각도 회피. 비용 없이 바로 적용 가능(업로드 UX 안내 문구 수준).
- **TTS 오디오 품질**: 노이즈가 섞인 음성이 립싱크 정확도를 저하시킨다는 문제의식의 논문 존재("A Lightweight Pipeline for Noisy Speech Voice Cloning and Accurate Lip Sync Synthesis").
- **영상 길이-드리프트 상관관계**: Higgsfield는 30초 이내로 완화 가능하다는 방침이 있으나, 타 벤더가 동일 임계치를 공식화한 근거는 확인하지 못함(불확실).
- **CodeFormer 등 후처리**: 실제 사례 존재(VividWav2Lip 등)하나 부작용 보고됨 — 입 주변이 흐려지거나 identity가 미세하게 바뀌는 문제. 립싱크 정확도 관점에서는 오히려 리스크가 될 수 있음.

### 시장 사용 현황

| 서비스 | 사용 기술/벤더 | 확실성 |
|--------|---------------|--------|
| **MyHeritage Deep Nostalgia** | D-ID 기술 라이선스 (reenactment 방식) | 확인됨 (TechCrunch, D-ID 공식 블로그) |
| **StoryFile** | AI 합성 아님 — 사전 녹화 영상을 인덱싱해 재생하는 방식 | 확인됨 |
| **HereAfter AI** | "Life Story Avatar" 언급되나 구체 기술 스택 확인 불가 | 불확실 |
| **Eternos.life** | 음성 클론 중심, 영상 아바타 컴포넌트 확인 안 됨 | 불확실 |
| **국내 서비스** | AI 립싱크 기반 "디지털 유언 영상" 서비스 사례를 찾지 못함 | 근거 부족 |

### 결정 사항 (2026-07-06)

9분할/멀티레퍼런스 전처리 파이프라인은 **현재 스킵**하기로 결정. 이유: (1) 해결하려는 문제(temporal consistency)와 검증된 효과(image identity consistency)가 다른 층위이고, (2) 5개 벤더 모두 멀티 이미지 미지원이라 별도 신규 기능 개발이 필요하며, (3) 아직 어떤 벤더를 최종 채택할지 사용자가 직접 A/B 테스트로 결정하기 전이라 선제 투자가 낭비될 위험이 큼. 대신 HeyGen 공식 권장 소스 사진 조건(정면·균일 조명·중립 표정)을 업로드 UX 안내로 반영하는 것을 저비용 대안으로 우선 적용. 벤더 확정 후 필요 시 해당 벤더에 멀티레퍼런스 지원 여부를 직접 문의해 2단계 파이프라인 추가 여부를 재검토.

## 10. 립싱크 벤더 재조사 및 최종 후보 확정 (2026-07-06)

### 배경

기존 5개 후보(Higgsfield/SadTalker/Hedra/HeyGen/D-ID)로 범위를 한정하지 않고, "사진+음성 → 입모양만 자연스럽게 맞추면 되는" 단순한 요구사항에 맞춰 완전히 백지 상태에서 재조사를 진행함. Gemini로 대체 가능한지도 확인함.

### Gemini 대체 가능 여부 (재확인)

Google Gemini(Omni Flash 포함)는 "정지 사진 + 음성 → 립싱크 영상"을 공식적으로 지원하지 않음 — 딥페이크 악용 방지를 위해 의도적으로 차단된 기능(VentureBeat 보도 확인). "Gemini Pro 아바타", "Gemini Nano Banana" 등을 표방하는 사이트들은 실제로는 Kling Avatar, Latiai Lip Sync 등 전혀 다른 벤더 모델을 "Gemini"라는 이름으로 재판매하는 제3자 서비스임 — 진짜 Gemini API가 이 기능을 수행하는 게 아님. 커뮤니티 우회 시도도 뚜렷한 성공 사례를 찾지 못함(애초에 Gemini/Nano Banana는 정지 이미지 생성 모델이라 영상 생성 자체가 기능 범위 밖). 결론: Gemini로 대체 불가.

### 경량 오픈소스 립싱크 모델 조사

- **Wav2Lip(원본, Rudrabha)**: 이 분야 원조 모델(GitHub 1.3만+ 스타, 논문 인용 1,445+회). 그러나 **라이선스가 개인/연구 목적만 허용하며 상업적 사용은 원저자에게 별도 문의가 필요**함. 2026년 기준 화질은 dated 평가(입 주변 블러·블록 아티팩트, 립 지터 문제).
- **Wav2Lip-HD/GFPGAN**: Wav2Lip 결과물에 GFPGAN/Real-ESRGAN 초해상도를 덧씌운 커뮤니티 확장판. 화질은 개선되나 후처리 단계 추가로 연산비용·시간 증가, 라이선스 이슈는 원본과 동일하게 승계.
- **VividWav2Lip**(2024 논문): SE-residual block + CodeFormer 복원 결합, Wav2Lip 대비 약 5% 개선 보고(학술 벤치마크 기준, 실서비스 검증 자료 부족).
- **MuseTalk**(Tencent 계열 TMElyralab): **MIT 라이선스**로 상업 이용 제한 없음. V100 기준 30fps+ 실시간 처리 가능, 속도-화질 균형 우수. Fal/Sieve/Replicate에서 API로 제공되어 자체 호스팅 없이 사용 가능.
- **LatentSync**(ByteDance): Stable Diffusion 기반, 커뮤니티에서 화질 최고 평가(MuseTalk 대비 "outstanding" 언급). 라이선스는 openrail++로 상업적 이용 조건이 불확실 — 확인 필요.
- **EchoMimic/Hallo/LivePortrait**: 표정·고개 움직임까지 생성하는 풀 talking-head 계열. "입만 맞추면 되는" 요구사항 대비 과스펙으로 판단.

### 신규 발굴 상용 후보

- **Sync.so**(Sync Labs): Wav2Lip 원저자들이 만든 상용 후신. 초당 4~13.3센트(또는 구독 $5~49/월). 개발자 문서·품질 평가 우수. "오디오 기반 립싱크"에 특화된 목적성 제품.
- **Kling AI Avatar**: 사진+오디오 한 장으로 장시간 말하기/노래 영상 생성, Fal 경유 API 존재. 정확한 단가는 크레딧제라 추가 확인 필요.
- **Vozo**: 멀티스피커 립싱크 지원, "LipREAL" 브랜딩. 리뷰 자료 상대적으로 적음.
- **Akool**: 저가($15~249/월대)이나 립싱크 정확도 리뷰가 HeyGen/Tavus 대비 낮음(7/10대 평가).
- **Tavus/Simli**: 실시간 대화형 아바타 특화 — 사전녹화 단발 영상인 온담 용도엔 과스펙.

### 시장 검증 (동일 유스케이스 기존 서비스)

"사진+음성 → 추모/고인 영상" 유스케이스가 이미 상용화된 니치임을 확인 — Vidnoz "Dead Person AI Video Maker", FlexClip 고인 목소리 복원 가이드, Opus.pro "Memorial Video Maker" 등이 실제 존재. MyHeritage Deep Nostalgia는 D-ID 기술을 라이선스해서 사용 중(기존 9번 섹션에서도 확인된 내용).

### 최종 확정 — 실제 구현·테스트 대상 3개 벤더

| 순위 | 벤더 | 선정 이유 |
|---|---|---|
| 1 | Sync.so | 목적성 정확히 일치(오디오→립싱크 전용), 상용 라이선스 안전, 초당 4~13.3센트로 저렴 |
| 2 | MuseTalk (Fal/Replicate API 경유) | MIT 라이선스로 상업 이용 완전 자유, 실시간 처리 검증됨, 자체 호스팅 불필요 |
| 3 | D-ID | 성숙·안정적 프레임워크(기존 PRD 원안), 분당 $0.05~0.2로 저렴, 상용 라이선스 안전 |

### 제외 결정 및 사유

- **Higgsfield**: 최초 검토 시 "이미 구현돼 있어 추가 비용이 0"이라는 이유로 최종 후보에 포함됐으나, 이는 정당한 선정 기준이 아님(매몰비용 논리). 다른 기준(비용·품질)으로 재평가한 결과 4개 후보 중 가장 비싸고($149+/월) face drift·낮은 시간적 일관성(3.4/10) 약점까지 있어 최종 제외.
- **Wav2Lip(원본)**: 화질 dated + 상업적 이용 시 라이선스 리스크(원저자 문의 필요) — 품질과 법적 리스크 모두 문제
- **Akool**: 립싱크 정확도 7/10대로 타사 대비 낮게 평가됨
- **SadTalker**: 두 차례 조사에도 상업 라이선스 조건을 확인하지 못함 — 유료 서비스에 쓰기엔 불확실성 남아 MuseTalk로 대체
- **Hedra/HeyGen**: 품질은 상위권이나 "입만 맞으면 되는" 낮은 기술 요구 수준 대비 과스펙·고비용 — 적합도 기준 제외
- **LatentSync**: 화질 최고 평가받지만 상업 라이선스(openrail++) 조건 불확실 — 확인 전까지 보류
- **Tavus/Simli**: 실시간 대화형 특화라 사전녹화 단발 영상 용도에 부적합
