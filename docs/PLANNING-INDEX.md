## 4. 오너 결정 대기 (2026-08-22 기준)

2026-08-21에 3건(보관구독·가격·추모관)이 확정됐고, 그 후 문서 진단에서 **결정되지 않은 채 방치된 항목 9건**이 새로 드러났다. 소유자·기한 없이 떠 있는 것들이라 여기 모은다.

| # | 미결정 항목 | 무엇이 막히는가 |

| 2 | **펫 구독 가격·티어** | 코드엔 이미 값이 박혀 있다(`pet_archive 4900`). PRD는 2티어, 전략 문서는 미정 - 3곳이 다름 |

### 사업 판단에 직결되는 새 발견 (09·12 문서)
- **CAC 2만원을 넘으면 "사진관 미끼 + 영상편지 업셀" 모델이 성립하지 않는다.** 사진관 기여이익 8,725원 / 영상편지 44,859원 기준, 필요 업셀 전환율이 CAC 2만원에서 25%, 3만원에서 47%가 된다. CAC 4.5만원 이상은 BEP 자체가 없다
- **BEP(인건비 300만원 가정, 오가닉)**: 영상 편지 월 73건. CAC 3만원이면 월 221건
- **재처리율은 무시 가능**(-53원). 원가를 이유로 재처리를 제한할 근거가 없다 → SPEC-02의 관대한 재처리 원칙이 옳았다
- **다년 보관 원가는 5년에 81원**(단건가의 0.17%). 보관 기간 N은 원가 제약이 아니라 법률·신뢰 관점에서 정하면 된다
- **`ad_spend` 입력 수단이 없으면 CAC는 영원히 계산 불가** → 관리자 광고비 입력 화면이 P0

**실행(결정 아님) 대기**: 마이그레이션 적용 / 법무 초안 검토 발주 / D-ID·토스 등 벤더 계정 발급(`strategy/13-vendor-readiness.md`)

## 5. 문서 관리 규칙

- **카피·명칭**은 `strategy/11-brand-messaging`이 SSOT. 다른 문서와 어긋나면 11을 따른다.
- **개발 태스크**는 `strategy/06-dev-backlog`이 SSOT (DEV 번호).
- **기능 동작 정책**은 해당 `specs/SPEC-*`가 SSOT. PRD와 충돌 시 SPEC 우선.
- 결정이 바뀌면 해당 SSOT 문서부터 고치고, 이 인덱스의 3·4절 상태를 갱신한다.
- 충돌은 숨기지 말고 표면화한다(SPEC-00 통제 원칙).
