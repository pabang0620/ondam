# 온담 법무 문서 초안 (변호사 검토 요청용)

> ## 이 폴더의 문서는 전부 미검토 초안입니다
>
> - 세 문서 모두 **변호사가 아닌 작성자**가 온담의 기획·명세 문서와 실제 소스코드를 확인해 작성했습니다.
> - **법률 자문이 아니며, 검토와 수정 없이 서비스에 게시하거나 이용자 동의를 받아서는 안 됩니다.**
> - 목적은 완성된 약관 제공이 아니라, **변호사에게 검토를 의뢰할 수 있는 출발점**을 만들어 검토 리드타임을 줄이는 것입니다.
> - 확신이 없는 부분은 문장을 지어내지 않고 `[검토 필요]` 표시로 남겼습니다. 표시된 항목은 **총 47건**이며, 이 문서 3장에 전부 모아 두었습니다.

## 3. 검토 요청 질문 전량 (47건)

> 이 절은 그대로 변호사에게 전달할 수 있도록 작성했습니다. 각 항목의 번호는 초안 문서 안의 `[검토 필요 xx-nn]` 표시와 1:1로 대응합니다.

### 3-1. 최우선 3건

먼저 답이 나와야 나머지 조항을 쓸 수 있는 항목입니다.

#### ① R-01 / R-02 - 전자상거래법 청약철회 7일과 "AI 처리 착수 후 환불 불가"의 관계

온담은 인공지능 처리가 시작된 후에는 환불하지 않는 것을 원칙으로 하고 있으나, 전자상거래법은 7일 내 청약철회권을 보장합니다. 디지털 콘텐츠의 "제공 개시" 예외에 해당하는지, 해당하려면 어떤 고지·동의 절차를 갖춰야 하는지 확정이 필요합니다.

특히 온담은 **개별 주문의 결과물을 사전에 보여줄 수 없는 구조**(인공지능 생성물이라 만들어 봐야 결과를 알 수 있습니다)이므로, 시용 제공이나 일부 제공 같은 대체 수단을 마련하기 어렵습니다. 이 제약 아래에서 예외 요건을 충족할 방법이 있는지가 핵심입니다.

결론에 따라 서비스의 결제 화면 설계와 환불 운영 원가가 함께 바뀝니다.

#### ② P-01 - 음성 클론용 목소리와 얼굴 이미지의 법적 분류

이 분류가 정해져야 동의 화면 구성, 위탁 계약 요건, 국외 이전 요건, 안전조치 수준이 전부 정해집니다. 온담은 목소리와 얼굴을 본인 확인이 아니라 **콘텐츠 생성 목적**으로 처리하는데, 이 목적 차이가 민감정보(생체인식정보) 해당 여부 판단에 영향을 주는지가 쟁점입니다.

#### ③ T-05 / T-17 - 사망 증명 서류 확인 의무와 오전달 책임

온담은 유가족이 제출한 서류를 담당자가 검수한 후 고인의 영상을 수신인에게 전달합니다. 서류가 위조되었거나 검수 착오로 잘못된 사람에게 전달되면 **되돌릴 수 없는 손해**가 발생합니다(수신인이 영상을 내려받을 수 있습니다). 회사가 부담하는 확인 의무의 수준과 책임 한계, 그리고 어떤 서류를 요구해야 하는지가 함께 결정되어야 합니다.
