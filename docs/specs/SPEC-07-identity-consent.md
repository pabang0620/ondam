# SPEC-07. 본인확인 강도·동의 수집·탈퇴 처리

## PRD 대비 변경
PRD의 인증은 SMS 6자리 코드 수준이고, PASS/NICE 등 본인확인 서비스·연령 확인·탈퇴 시 유언 데이터 처리 정책이 없다. 본 SPEC이 상품별 확인 강도를 차등 확정한다.

## 1. 원칙: 상품 민감도에 비례한 확인 강도

| 행위 | 요구 강도 | 근거 |
|---|---|---|
| 회원 가입·사진관 구매 | 이메일 or 카카오 + 휴대폰 SMS 인증 (현행 유지) | 저위험. 진입 장벽 최소화가 우선 |
| 영상 편지 제작 (음성 클론 동의 시점) | 휴대폰 SMS 인증 **필수** + 강화 동의 절차 (2절) | 음성·초상 이용의 본인성 확보 |
| **본인확인 서비스(PASS/NICE) 도입** | **1차 출시에서는 도입하지 않는다** | 아래 상세 |
| 사후 공개 요청 (유가족) | 서류(사망증명서) + 관리자 검수 (현행) + 요청자 휴대폰 인증 추가 | 오전달 방지 |
| 열람 (수신인) | 토큰 + 휴대폰 뒤 4자리 (SPEC-05) | 비회원 마찰 최소화 |

### PASS/NICE 미도입 근거와 보완
- 이 서비스의 법적 위험은 "가입자가 타인을 사칭해 영상을 만드는 것"인데, 실명확인만으로는 이를 못 막는다 (본인 명의로 타인 사진·음성을 올리는 게 실제 위험). 핵심 방어는 실명확인이 아니라 **업로드 데이터의 본인성 확인**이다 → 2절의 동의 녹취로 대응
- 결제(토스)가 이미 카드 실명 기반이라 최소한의 실명성은 확보됨
- 도입 비용·이탈률 대비 효익이 낮다. 단, 분쟁 발생 실적이 생기면 재검토 (법률 검토 항목에 포함, strategy/07 2절 2번)

## 2. 강화 동의 절차 (영상 편지 전용)

기존 `user_consents`(privacy/voice_clone/ai_video/marketing + IP/UA) 위에 추가:

1. **동의 문장 낭독 녹음**: 음성 샘플 녹음 첫 단계에서 고정 문구를 본인이 낭독한다. 예: "나 ○○○은 내 목소리와 사진으로 영상 편지를 만드는 것에 동의합니다."
   - 이 녹음이 (a) 본인 육성 동의 증빙 (b) 음성 클론용 샘플의 일부, 두 역할을 겸한다 → 절차 추가 부담 없음
   - 파일은 KMS 암호화 보관, `voice_samples`에 consent 플래그로 구분 저장
2. **동의 화면 원칙**: 체크박스 일괄 동의 금지. 음성 클론·AI 영상 생성·사후 전달 3건은 각각 화면 분리, 쉬운 말 설명 1문단씩 (어르신 UX)
3. 선물 동선(SPEC-01)에서도 동일: 동의·낭독은 수행자(부모) 본인만 가능

## 3. 연령·특수 케이스

| 케이스 | 정책 |
|---|---|
| 만 14세 미만 | 가입 불가 (생년 입력 검증). 법정대리인 동의 체계는 도입하지 않음 (타겟과 무관) |
| 수신인이 미성년 | 전달 시점에 미성년이면 보호자 경유 전달 안내 (관리자 확인 항목). 세부 기준은 법률 검토 5번 반영 |
| 위독·의사표시 곤란 상태의 제작 시도 | 서비스는 본인 수행이 원칙이므로 시스템으로 막지 않되, 약관에 "본인의 자유로운 의사로 제작" 명시. 분쟁 시 동의 낭독 녹음이 증빙 |

## 4. 회원 탈퇴·데이터 처리

| 데이터 | 탈퇴 시 처리 |
|---|---|
| 일반 회원 데이터 | soft delete 후 유예 기간 경과 시 완전 삭제 (현행 컨벤션) |
| 음성 샘플·클론 모델 | **즉시 완전 삭제** (유예 없음. 가장 민감한 데이터) |
| 제작 완료 영상 (전달 예약 없음) | 탈퇴 시 삭제 (본인 소유물) |
| 제작 완료 영상 (**전달 예약 있음**) | **탈퇴 화면에서 명시적 선택 강제**: "전달 예약을 유지하고 탈퇴" vs "예약 취소하고 모두 삭제". 기본값 없음, 선택 없이는 탈퇴 진행 불가 |
| 유지 선택 시 | 계정은 삭제하되 전달에 필요한 최소 데이터(영상·수신인·검수용 신원 정보)만 분리 보관, 약관에 근거 명시 |
| 결제 기록 | 법정 보존 기간 유지 후 파기 |

- "전달 예약 유지 탈퇴"는 이 서비스만의 특수 케이스로, 약관·개인정보처리방침에 별도 조항 필수 (법률 검토 3번에 포함)

## 수용 기준
1. 영상 편지 플로우에서 동의 낭독 녹음 없이는 다음 단계 진행 불가, 녹음이 consent 플래그와 함께 저장됨
2. 동의 3건이 화면 분리되어 있고 일괄 체크 UI가 없음
3. 탈퇴 시나리오 3종(예약 없음/예약 유지/예약 취소) E2E, 음성 데이터 즉시 삭제 확인
4. 사후 공개 요청에 요청자 휴대폰 인증이 추가됨
