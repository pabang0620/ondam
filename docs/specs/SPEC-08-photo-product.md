# SPEC-08. AI 사진관 상품 구성·재처리 상세

## PRD 대비 변경
PRD는 "9,900원/세트" 단일가와 처리 4종(복원 P0 / 컬러화 P1 / 배경 P1 / 정장합성 P0)을 나열했을 뿐 세트 구성·옵션 관계가 없다. 본 SPEC이 상품 구성을 확정한다.

## 1. 상품 구성: "옵션 선택"이 아니라 "전부 자동 적용"

**결정: 사용자는 처리 옵션을 고르지 않는다.** 사진 1장을 올리면 아래가 자동 파이프라인으로 전부 적용된 결과 세트를 받는다.

- 근거: 5060에게 "복원/컬러화/배경제거 중 선택"은 이해 비용이 크고 장바구니식 옵션 UI는 이탈 지점이다. 쐐기 상품의 목적은 마진 최적화가 아니라 전환 최대화 (strategy/03)

### 세트 내용물 (1주문 = 원본 1장 기준)

> **[2026-08-22 정정] 실제 파이프라인은 Gemini다.** 이 문서와 PRD가 전제한 Real-ESRGAN + remove.bg 조합은 구현되지 않았다. `.env`에 `GEMINI_API_KEY`만 있고 remove.bg 키가 없으며, `photoWorker`가 Gemini로 전 처리를 수행한다(`docs/AI_STACK_RESEARCH.md` 4절이 채택 근거). **코드가 정본이다.** DEV-02 원가 실측도 Gemini 기준으로 해야 한다.

| # | 결과물 | 파이프라인 (실제) |
|---|---|---|
| 1 | 복원본 | Gemini 화질 복원 (+흑백이면 컬러화 자동 판단) |
| 2 | 원본 색감 유지본 | 복원만 적용 (컬러화가 어색할 경우의 안전판) |
| 3 | 증명·영정 규격본 | 배경 정리 + 규격 크롭 |
| 4 | 정장 합성본 | 사용자가 유일하게 고르는 것: **용도 1택 (장례용/증명용/취업용)** + 정장 스타일 2~3종 중 1택 |

- 유일한 선택지는 "용도"다 (PRD의 3타입 유지). 그 외 선택 UI 없음
- 흑백/컬러 자동 판단이 틀릴 수 있으므로 1·2번을 모두 제공하는 것이 재처리 요청을 줄이는 장치

### 가격·수량
- 9,900원 = 원본 1장 → 세트 4종
- 추가 원본: 장당 4,900원 (같은 주문 내, 파이프라인 원가 체감 반영. DEV-02 원가 실측 후 확정)
- 업셀 고리: 결과물 화면에서 "이 사진과 목소리로 영상 편지 만들기" (strategy/03)

## 2. 입력 검증·안내 (실패 예방이 곧 CS 예방)

- 허용: JPG/PNG/HEIC, 최대 20MB. HEIC은 서버 변환
- 업로드 직후 프리체크 (결제 전 차단): 해상도 하한 미달, 얼굴 미검출, 얼굴 과소(원거리 단체사진) → 쉬운 말 안내와 함께 재업로드 유도. "이 사진은 얼굴이 너무 작아서 잘 안 나올 수 있어요. 그래도 진행할까요?" (경고 후 진행 허용, 단 이 경우 품질 불만 재처리 기준 고지)
- 단체 사진: 얼굴 다수 검출 시 대상 인물 선택 UI (탭 1회)
- 프리체크 통과 후에만 결제 진입 → "결제했는데 실패" 케이스를 구조적으로 축소

## 3. 처리·수령 UX

- 진행 화면: 단계명을 사람 말로 ("사진을 곱게 다듬는 중이에요") + 완료 시 알림톡 통지 (SPEC-04). 화면을 떠나도 됨을 명시
- 결과 화면: 전후 비교 슬라이더, 세트 4종 개별 다운로드 + 전체 저장, 카카오톡 공유(DEV-09), 보관함 자동 저장
- 인쇄 안내: 영정 규격본의 실물 인쇄 가이드(권장 사이즈·인화 방법) 텍스트 제공. 인화 제휴는 Phase 4 검토 항목으로만 기록

## 4. 재처리 규정 (SPEC-02 연계 상세)
- 무료 재처리 1회: 결과 화면 "마음에 안 들어요" → 사유 선택 → 해당 항목만 다시 실행 (세트 전체 재실행 아님, 벤더 원가 절약)
- 재처리는 파라미터를 바꿔 실행 (동일 파라미터 재실행은 같은 결과가 나올 가능성이 높으므로, 파이프라인에 재처리용 대안 프리셋을 1개 이상 둔다)
- 재처리 후 불만 → 환불 요청 (SPEC-02 관리자 승인 환불)

## 수용 기준
1. 업로드 → 용도 1택 → 결제 → 세트 4종 수령까지 선택지가 용도 외에 없음
2. 프리체크가 저해상도·얼굴 미검출을 결제 전에 차단하고, 경고 후 진행 케이스가 로그에 구분 기록됨
3. 단체 사진 인물 선택 동작
4. 항목 단위 재처리가 세트 전체를 재실행하지 않음
