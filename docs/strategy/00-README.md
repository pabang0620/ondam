## 코딩 AI에게 작업을 맡길 때

1. 태스크는 반드시 [06-dev-backlog.md](06-dev-backlog.md)의 태스크 ID 단위로 지시한다 (예: "DEV-01 수행").
2. 코딩 AI에게 함께 주입할 컨텍스트:
   - 해당 태스크 항목 전문 (배경·대상 파일·수용 기준)
   - 프로젝트 로컬 규칙: `ondam/.claude/CLAUDE.md` (응답 포맷, 레이어 컨벤션, 보안 규칙, 어르신 UX 규칙)
   - 필요 시 `docs/PRD.md`의 해당 기능 섹션
3. 전략적 판단(가격·명칭·범위)은 코딩 AI가 바꾸지 않는다. 판단 변경이 필요하면 이 문서 세트를 먼저 수정하고 태스크를 갱신한다.
4. 태스크 완료 시 06 문서의 해당 항목 상태를 갱신한다 (TODO → DONE + 커밋 해시).

## 핵심 결론 요약 (전체 문서의 한 줄 압축)

- **시장 방향은 유효하다**: 죽음 준비에 선지불하는 소비(상조 1,131만 명·선수금 11.3조)가 검증돼 있고, "상조·장례식장 계약 없이 개인이 1~5만 원대로 사는 AI 추모 상품"은 직접 경쟁자가 없는 공백이다.
- **최대 병목은 시장이 아니라 립싱크 기술 검증이다**: 벤더 어댑터 3종이 전부 미검증 추정 스펙 상태.
- **활성화 수순**: AI 사진관(9,900원)을 쐐기 상품으로 먼저 출시해 수요를 실측하고, 그 사이 립싱크 벤더 1곳을 확정한 뒤 영상 편지(구 유언장)를 티어 가격으로 출시한다.
- **포지셔닝 원칙**: "사후 재현"이 아니라 "생전 본인 동의 기반 기록·전달". 실구매자는 5060 본인보다 4050 자녀(선물 동선)일 가능성이 높다.
