## 1. 상품 라인업

### ① AI 사진관 (쐐기 상품)
| 항목 | 내용 |
|---|---|
| 구성 | 사진 복원(Real-ESRGAN) + 흑백 컬러화 + 배경 정리 + 정장(영정) 합성, 결과물 세트 제공 |
| 가격 | **9,900원/세트** (유지. 심리적 저항선 1만 원 아래, 결제 경험 생성이 목적) |
| 역할 | 고객 획득·바이럴·업셀 진입점. 단독 수익 상품이 아니다 |
| 업셀 | 결과물 전달 화면에서 영상 편지 안내 ("이 사진과 목소리로 영상 편지를 남길 수 있어요") |
| 부가 | 결과물은 자동으로 개인 보관함(추모관 공간)에 저장 → 재방문 고리 |

### ② 마지막 영상 편지 (코어 상품, 구 "AI 디지털 유언장")
> **확정(2026-08-21 오너 채택)**: **베이직 49,000원 단일가로 출시**하고, 전환율·객단가 데이터를 본 뒤 스탠다드·프리미엄을 순차 추가한다. 처음부터 3티어를 노출하지 않는다(5060 선택 피로 최소화, 09 문서).

| 티어 | 구성 | 가격(안) | 출시 |
|---|---|---|---|
| 베이직 | 사진 1장 + 음성 샘플 → 립싱크 영상 1편(1분 내), 수신인 1명, 사후 전달 | **49,000원** | **1차(단독 출시)** |
| 스탠다드 | 영상 2편 or 3분 확장, 수신인 3명(가족별 개별 메시지 = 기존 `will_beneficiaries` 구조 활용) | 99,000원 | 2차(데이터 후) |
| 프리미엄 | 영상 다편 + 고화질 + 수신인 ≤10명 + 기일 자동 재전달 | 199,000원 | 2차(데이터 후) |

- 근거: Vaice가 건당 약 60만 원에 월 300명을 받는 시장. 원가율이 낮아(09 문서) 마진은 어느 가격도 문제가 아니며, 관건은 전환율×객단가다. 그래서 마진 방어가 아니라 지불의사 상방 확보용으로 티어를 두되, 선택 피로를 피해 단일가부터 시작한다.
- 스탠다드/프리미엄 수치·구성은 2차 도입 시점에 1차 데이터로 재조정한다. 프리미엄 "무제한 수신인"은 검수·발송 비용 통제 위해 최대 10명으로 확정(SPEC-05).
- 법적 효력 없음을 구매 플로우와 약관에 명시한다 (07 문서).

### ③ 반려동물 아카이브 (확장 A, 유일한 구독)
| 항목 | 내용 |
|---|---|
| 무료 | 기본 아카이브(사진 업로드 제한, 기일 알림) - 유입용 |
| 구독 | 월 구독: 무제한 보관 + AI 초상화 매월 N매 + 기일 추모 페이지 |
| 단건 | AI 초상화 단품 구매 (구독 비가입자용) |
| 제휴 | 동물장묘업체(전국 86곳) 제휴: 화장 고객에게 아카이브 개설 쿠폰 제공 |

- 경쟁이 가장 옅은 지대(AI 활용은 재심 1곳). 화장 직후가 감정적 전환율이 가장 높은 시점이므로 제휴가 곧 획득 채널이다.

### ④ 추모관 (부속 기능, 비상품)
- 독립 판매하지 않는다. ①②③ 구매자의 보관·열람·공유 공간.
- slug 접근 코드 구조(기구현) 유지. 유가족 열람 화면이 곧 신규 고객 접점(방문 유가족에게 사진관 안내)이라는 점만 설계에 반영.

## 2. 결제 동선 2종 (핵심 UX 결정)

### A. 본인 셀프 동선 (5060)
- 극단적 단순화: 한 화면 한 행동, 버튼 48px+, 폰트 16px+ (기존 로컬 CLAUDE.md 규칙 유지)
- 단계: 사진 올리기 → (영상 편지면) 음성 녹음 → 결제 → 끝. 회원가입은 카카오 1탭 우선.

### B. 자녀 선물 동선 (4050) - **신규 구축 필요, 최우선 전환 동선**
1. 자녀가 상품 선택·결제 → "부모님께 보낼 링크" 생성
2. 부모는 링크 클릭 → 로그인 없이(또는 최소 인증) 사진 업로드·음성 녹음만 수행
3. 완료 시 자녀·부모 양쪽에 알림
- 이 동선이 있어야 "역량 60.8%" 문제를 우회하고 시즌(어버이날·명절) 캠페인이 작동한다.
- 개발 태스크: DEV-10 (06 문서)

## 3. 어르신 UX 원칙 (기존 규칙 승계 + 추가)

기존 `ondam/.claude/CLAUDE.md`의 규칙(버튼 48px+, 폰트 16px+, WCAG AA)을 유지하고 다음을 추가한다:

1. **음성 녹음 UX가 승부처다**: 영상 편지의 유일한 어려운 조작. 녹음 가이드 문장 제시(읽기만 하면 됨) + 재녹음 무제한 + 실패해도 진행 가능한 대체 경로(전화 녹음 안내 등) 검토.
2. **진행 상태를 사람 말로**: "AI 처리 중 37%"가 아니라 "사진을 곱게 다듬고 있어요. 끝나면 문자로 알려드릴게요". BullMQ 비동기 처리 완료 시 알림톡/SMS 통지 필수.
3. **실패 시 환불 자동화**: AI 처리 실패(립싱크 벤더 오류 등) 시 자동 환불 + 사과 메시지. 시니어 타겟에서 CS 분쟁은 브랜드 치명상.
4. **전화 문의 번호 노출**: 5060 신뢰 장치. 랜딩·마이페이지에 상시 노출.

## 4. 신뢰·투명성 장치 (전환율 장치이기도 함)

- 랜딩에 명시: "본인이 생전에 직접 남기는 기록입니다" / "사망증명서 확인과 관리자 검수를 거쳐 전달됩니다" / "언제든 삭제할 수 있습니다"
- 복원 전후 비교 슬라이더(사진관), 실제 제작 예시 영상(모델 출연 샘플)을 랜딩 최상단에.
- 가격 전면 공개(경쟁자 전원이 가격 비공개 문의형인 것 자체가 차별화 포인트다).
