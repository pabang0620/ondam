# 04. GTM 플랜: 채널·퍼널·캠페인·KPI

> 상품 전제는 [03-product-pricing.md](03-product-pricing.md), 단계 게이트는 [05-execution-phases.md](05-execution-phases.md) 참조.

## 1. 퍼널 설계

```
[인지] 4050 자녀 채널 콘텐츠 (복원 전후·사연)
   ↓
[유입] 랜딩: 사진관 9,900원 (가격 전면 공개)
   ↓
[첫 결제] 사진관 세트 → 결과물 + 보관함 생성
   ↓
[업셀] 결과물 화면에서 영상 편지 안내 → 티어 선택
   ↓
[확산] 결과물 공유(가족 단톡 전송) → 신규 유입
[재방문] 기일·명절 알림, 펫 아카이브
```

핵심 지표는 "사진관 → 영상 편지 업셀 전환율"이다. 사진관은 이 전환율이 나와야 미끼상품으로 성립한다.

## 2. 채널 우선순위

### 1순위: 자녀 세대 D2C 콘텐츠 (비용 최소, 자산 축적형)
- 인스타그램 릴스/유튜브 쇼츠: 복원 전후 비교, 부모님 사연 콘텐츠. "부모님 옛날 사진 복원해드렸어요" 포맷은 자생 확산력이 있음
- 커뮤니티: 맘카페·시니어 자녀 커뮤니티에 체험 후기형 진입 (광고 티 제거)
- 콘텐츠 원칙: 죽음을 정면에 내세우지 않는다. "기억·기록·선물" 프레임. 사진관 콘텐츠로 열고 영상 편지는 랜딩에서 소개

### 2순위: 시즌 캠페인 (전환 집중 윈도우)
- 어버이날·설·추석·부모님 생신. 선물 동선(03 문서 B동선)이 완성된 뒤 집행
- 시즌 한정 패키지: "사진관 + 영상 편지 베이직" 묶음가

### 3순위: 펫 축 제휴 (B2B2C, 영업 리스트가 유한함)
- 전국 동물장묘업체 86곳 리스트업 → 제휴 제안 (화장 고객에게 아카이브 개설 쿠폰)
- 화장 직후가 전환율 최고 시점. 업체에는 "고객 사후 관리 서비스"로 소구
- 21그램 등 정찰제·브랜드형 업체 우선 접촉

### 4순위: 중소 상조·장례식장 화이트라벨
- 대형(프리드라이프)은 딥브레인 선점 → 제휴 없는 중소 상조사·지역 장례식장 대상
- 온담 상품을 그들의 부가서비스로 공급. 단, 셀프서브 D2C가 검증된 뒤에 착수 (제품 없이 영업하지 않는다)

### 하지 않는 채널
- 5060 본인 대상 퍼포먼스 광고(역량 문제로 전환 비효율), TV/오프라인 광고, 추모관 단독 홍보

## 3. 유료 광고 테스트 (Phase 2에서 소액)

- 목적: CAC 실측. 메타(인스타) 4050 타겟, 사진관 랜딩으로 소액 집행
- 판정 기준:
  - CAC < 사진관 마진: 사진관 단독으로도 확장 가능
  - CAC > 사진관 마진: 사진관은 미끼로 규정, (CAC) < (사진관 마진 + 업셀 전환율 × 영상 편지 마진) 성립 여부로 재판정
- 판정 전에는 광고 예산을 늘리지 않는다

## 4. KPI 체계

### North Star
**"전달 예약된 영상 편지 수"** (결제가 아니라 제작 완료·전달 예약까지 간 건수. 제품 가치의 실현 단위)

### Phase별 핵심 지표
| Phase | 지표 | 의미 |
|---|---|---|
| 2 (사진관 출시) | 방문 → 결제 전환율 | 랜딩·가격 수용성 |
| 2 | 결제 → 결과물 수령 완료율 | AI 파이프라인 신뢰성 (실패·환불율 포함) |
| 2 | 결과물 공유율 | 바이럴 계수의 선행 지표 |
| 2 | CAC (소액 광고 실측) | 확장 가능성 판정 |
| 3 (영상 편지 출시) | 사진관 → 영상 편지 업셀 전환율 | 퍼널 성립 여부 |
| 3 | 티어 분포 (베이직:스탠다드:프리미엄) | 가격 설계 검증 |
| 3 | 선물 동선 비중 (자녀 결제 %) | 포지셔닝 가설(결정 3) 검증 |
| 3 | AI 처리 실패율·환불율 | 벤더 품질 모니터링 |

### 가설 검증 목록 (지표로 판정할 것)
1. 자녀가 주 결제자다 → 선물 동선 비중으로 판정
2. 사진관이 업셀 퍼널로 작동한다 → 업셀 전환율로 판정
3. 49,000원은 저가 침투로 유효하다 → 티어 분포와 전환율로 판정
4. 펫 화장 직후 제휴 쿠폰이 전환된다 → 제휴 쿠폰 등록률로 판정

## 5. 브랜드 메시지 뼈대 (카피 지침)

- 태그라인 후보: "기억을 간직하는 가장 쉬운 방법" / "1만 원부터 시작하는 기억 보관소"
- 금지: "유언장"(법적 오인), "고인 재현"(윤리 프레임), 죽음 공포 소구
- 권장 프레임: 선물, 기록, 효도, "목소리를 남기다"
- 모든 카피에 가격 명시 (경쟁자 전원 가격 비공개 → 투명성 자체가 차별화)
