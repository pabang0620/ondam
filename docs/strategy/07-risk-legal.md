## 2. 법률 체크리스트 (전문가 검토 1회 필요 항목)

출시 전 변호사 검토를 받을 항목. 아래는 검토 요청서에 넣을 목록이다 (자체 판단으로 갈음하지 않는다).

1. **유언 효력 고지**: "본 서비스의 영상은 민법상 유언의 효력이 없다"는 고지 문구·위치의 적정성
2. **본인 동의 확보**: 음성·초상 이용 동의(전자적 동의의 증빙력), `voice_consent_at` 등 동의 시각 기록의 충분성
3. **사후 데이터 처리**: 회원 사망 후 데이터의 법적 지위(고인 정보는 개인정보보호법 비적용이라는 공백 하에서의 자체 정책), 유족의 삭제 요청권 처리 기준
4. **사망증명서 검수**: 서류 진위 확인의 주의 의무 범위, 오전달(잘못된 수신인) 시 책임 한계
5. **미성년·제3자 수신인**: 수신인이 미성년이거나 연락 불가일 때의 전달 정책
6. **전자상거래법**: 디지털 콘텐츠 청약철회(제작 착수 후 환불 기준), 구독 해지 고지
7. **표시광고**: "AI 복원" 결과물의 품질 표현 범위(과장 광고 리스크)
8. **약관·개인정보처리방침**: 위 전부를 반영한 약관 초안 검토

## 3. 윤리 원칙 (대외 공표용 초안)

서비스 페이지 "온담의 약속" 섹션으로 게시할 초안:

1. **본인의 기록만 만듭니다**: 온담의 영상은 본인이 생전에 직접 촬영·녹음한 기록으로만 제작합니다. 제3자가 고인의 사진과 음성으로 의뢰하는 재현 영상은 만들지 않습니다.
2. **전달은 검수를 거칩니다**: 사망증명서 확인과 담당자 검수를 거친 뒤에만 지정된 분께 전달합니다.
3. **언제든 지울 수 있습니다**: 본인은 언제든 기록을 삭제할 수 있고, 삭제된 데이터는 복구하지 않습니다.
4. **데이터는 암호화해 보관합니다**: 음성·영상·서류는 암호화 저장하며, 접근 기록을 남깁니다.

## 4. 논란 대응 시나리오 (플레이북)

- **트리거**: "AI로 고인 재현" 관련 부정 보도·커뮤니티 이슈가 업계에 발생했을 때
- **대응 순서**:
  1. 온담이 직접 언급되지 않았으면 선제 보도자료를 내지 않는다 (프레임에 스스로 들어가지 않기)
  2. 문의가 오면 위 윤리 원칙 1번(생전 본인 기록만)으로 일관 답변
  3. 온담이 직접 언급되면: 윤리 원칙 전문 공개 + 검수 절차 설명 + 필요 시 해당 건 처리 이력(audit_logs) 기반 사실관계 공개
- **금지**: 경쟁사 비난, "우리는 다르다"식 비교 마케팅으로의 전용

## 5. 데이터 보관·파기 정책 (내부 기준 초안)

| 데이터 | 보관 | 파기 |
|---|---|---|
| 음성 샘플·클론 모델 | 본인 계정 유지 기간 | 본인 삭제 요청 즉시 + 탈퇴 시 (soft delete 유예 후 완전 삭제) |
| 완성 영상 | 전달 완료 후에도 수신인 열람 기간 동안 보관 | 수신인 전원 삭제 요청 시 |
| 사망증명서 | 검수 목적 달성 후 최소 보관 (법정 보존 기간 확인 필요 - 법률 검토 4번 항목) | 기간 경과 시 자동 파기 |
| 결제 정보 | 전자상거래법 보존 기간 | 기간 경과 후 파기 |

> 이 표의 기간 수치는 법률 검토(2절) 결과로 확정한다. 확정 전 임의 구현 금지.
