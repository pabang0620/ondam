# 09. 단위 경제성 (원가·마진 모델)

> 벤더 실사(08 문서, D-ID 확정)와 상품 구조(03 문서)를 근거로 상품별 건당 원가·마진을 추정한다.
> **모든 원가 수치는 추정치다.** 확정은 DEV-02(AI 원가 실측)의 실사용 청구 데이터로 한다. 이 문서는 "가격 티어 결정(승인 대기 3번)을 판단할 근거 틀"이다.
> 환율 가정: 1 USD = 1,350 KRW.

## 1. 상품별 건당 변동원가 (추정)

### AI 사진관 (9,900원/세트, 원본 1장 → 결과 4종)
| 항목 | 추정 원가 | 근거 |
|---|---|---|
| AI 이미지 처리(복원·컬러화·합성, Gemini 등) | 200~600원 | 결과 4종 생성. 실측 필요(DEV-02) |
| 배경 제거(remove.bg 등) | 100~300원 | 건당 종량 |
| S3 저장·전송 | 50원 미만 | 소용량 이미지 |
| **변동원가 합계** | **약 350~950원** | |
| **매출총이익(9,900원 기준)** | **약 8,950~9,550원 (마진율 90%+)** | 결제수수료(약 2.8%) 별도 |

→ 사진관은 원가율이 매우 낮다. 쐐기 상품으로서 **가격 인하 여력이 아니라 CAC 회수·업셀 전환이 관건**(04 문서 판정식).

### 마지막 영상 편지 (베이직 49,000원)
| 항목 | 추정 원가 | 근거 |
|---|---|---|
| 립싱크(D-ID, 1분 영상) | 약 950~1,300원 | 08 문서: $0.7~0.9/분 |
| 음성 클론·TTS(ElevenLabs) | 500~2,000원 | 클론 생성 1회 + 합성. 실측 필요 |
| 영상 후처리(ffmpeg)·S3 저장 | 100~300원 | |
| 관리자 검수·CS(사후 전달 1건 인건비 배분) | 변동 | 정성 비용, 별도 관리 |
| **변동원가 합계(AI)** | **약 1,550~3,600원** | |
| **매출총이익(49,000원 기준)** | **약 45,400~47,450원 (마진율 92%+)** | |

→ **베이직 49,000원의 마진율 우려는 근거가 약하다.** D-ID 원가가 예상보다 낮아, 티어 도입 여부와 무관하게 단건 마진은 충분하다. 즉 티어(승인 대기 3번)는 "마진 방어"가 아니라 **지불의사 상방 확보** 목적이다.

### 반려동물 아카이브 (구독)
| 항목 | 추정 원가 | 근거 |
|---|---|---|
| 스토리지(월, 사용자당) | 수십~수백원 | 사진 보관량 비례 |
| AI 초상화(월 N매) | 매당 200~600원 | 사진관과 유사 파이프라인 |
| **월 구독 원가** | 초상화 매수에 비례 | 구독가는 초상화 매수로 조절 |

→ 구독 원가의 대부분은 AI 초상화 매수다. **무료 티어의 초상화는 0매 또는 체험 1회로 제한**해야 유입-원가 균형이 맞는다.

## 2. 가격 티어 판단 (승인 대기 3번 근거 틀)

원가가 낮으므로 티어의 목적은 마진이 아니라 **세그먼트별 지불의사 포착**이다. 경쟁 앵커: Vaice 건당 약 60만 원.

| 티어 | 가격(안) | 원가율(추정) | 포지션 |
|---|---|---|---|
| 베이직 | 49,000원 | 3~7% | 대중 진입가. 수신인 1명, 1분 |
| 스탠다드 | 99,000원 | 2~4% | 수신인 3명 개별 메시지, 확장 길이 |
| 프리미엄 | 199,000원 | 1~2% | 수신인 다수(≤10), 고화질, 기일 재전달 |

- 세 티어 모두 원가율이 한 자리 수라, **어느 가격을 택해도 마진은 문제가 아니다.** 결정 변수는 "전환율 × 객단가"의 총합이다.
- 권장: **베이직 단일가로 출시해 실제 전환·객단가를 측정한 뒤, 스탠다드/프리미엄을 후속 추가**한다(가격 실험). 처음부터 3티어를 노출하면 5060 이용자의 선택 피로를 유발(디지털 역량 60.8%, 03 문서).
- 이 권장은 승인 대기 3번의 "티어로 간다/안 간다"를 "간다, 단 순차 도입"으로 좁힌 안이다. 오너 확정 필요.

## 3. 손익 시나리오 (개념, 실측 전)

North Star = "전달 예약된 영상 편지 수"(04 문서). 영상 편지 1건당 매출총이익 약 4.7만 원(베이직)에서 CAC·검수·CS를 차감한 것이 기여이익.

- 사진관은 낮은 객단가·높은 마진율이라 **획득·바이럴 엔진**, 영상 편지는 **이익 엔진**으로 역할 분담(02 문서 구조와 일치).
- 손익분기의 핵심 변수는 원가가 아니라 **CAC와 사진관→영상편지 업셀 전환율**이다. 따라서 Phase 2에서 이 두 지표를 먼저 실측한다(05 문서).

## 4. 원가 관리 규칙

1. 영상 편지는 D-ID 종량이므로, **AI 처리 실패 시 자동 환불**(SPEC-02)이 원가 누수를 막는 장치다. 실패 건 방치는 원가+CS 이중 손실.
2. 재처리는 항목 단위로만(세트 전체 재실행 금지, SPEC-08 4절) → 벤더 과금 절약.
3. 벤더 단가 인상·종료 리스크(strategy/07 R5)에 대비해 예비 벤더(Sync.so) 어댑터 스펙을 유지. 단 Sync.so는 원가 3배이므로 상시 사용 아님.
4. 실측 후 이 문서의 추정 수치를 실제 청구액으로 대체하고, 마진율이 티어별 목표를 밑돌면 가격을 재검토한다.
