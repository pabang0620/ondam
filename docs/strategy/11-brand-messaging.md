# 11. 브랜드 & 메시징 가이드

> 명칭·톤·카피 원칙을 한 곳에 고정한다. 산재한 카피 지침(02·03·04 문서)을 통합·현행화한 SSOT다.
> 모든 대외 문구(랜딩·앱·광고·SNS·알림)는 이 문서를 따른다.

## 1. 네이밍 (확정)

| 대상 | 명칭 | 상태 |
|---|---|---|
| 서비스(브랜드) | **온담** | 확정 |
| 영상 편지 상품 | **마지막 영상 편지** (짧게 "영상 편지") | **확정 2026-08-21** (구 "AI 디지털 유언장") |
| 사진관 상품 | **AI 사진관** | 확정 |
| 펫 상품 | **반려동물 아카이브** | 확정 |
| 추모 공간 | **추모관** (사람=비공개 / 펫=소유자 공개선택, SPEC-03) | **확정 (2026-08-21 오너 채택)** |

> **제품 반영 상태 주의 (2026-08-22)**: "마지막 영상 편지" 명칭은 **문서상 확정이나 제품에는 아직 미반영**이다. 프론트 20여 개 파일에 "유언장" 문자열이 남아 있다(DEV-05 미착수). 카피 작업 시 이 문서를 따르되, 화면에 옛 명칭이 보이는 것은 알려진 미완 상태다.

**"유언장" 사용 금지**: 법적 효력 오인 방지(02 문서 결정 2). 단, 법적 고지문 안의 "유언의 법적 효력은 없습니다" 표현은 예외로 허용.

## 2. 태그라인 (후보 → 권장)

- **권장 대표**: "기억을 간직하는 가장 쉬운 방법"
- 보조: "1만 원부터 시작하는 기억 보관소" / "부모님의 목소리를 남기세요"
- 선정 기준: 죽음을 앞세우지 않을 것, 쉬움·저가 진입을 담을 것, 선물/효도 정서와 연결될 것.
- 최종 1개 확정은 랜딩 제작(DEV-13) 시점에 오너가 택. 그 전까지 위 3개를 맥락별로 사용.

## 3. 브랜드 보이스 (톤)

- **따뜻하고 담백하게.** 과장·상술 어투 금지(메모리 카피라이팅 금지 원칙과 일치).
- **쉬운 말.** 전문용어·영어 최소화. 5060이 읽어 바로 이해되게(예: "AI 처리 중 37%" → "사진을 곱게 다듬고 있어요").
- **강요하지 않기.** 특히 죽음·사후 관련은 담담하게. 공포 소구 금지.
- **정직하게.** 가격·절차·한계를 숨기지 않음. 가격 전면 공개가 곧 차별화(경쟁사 전원 비공개).

## 4. 메시징 기둥 (4개)

1. **쉬움**: "복잡하지 않아요. 사진 한 장이면 됩니다." / 무계정 선물 링크, 알림톡 안내.
2. **신뢰·안전**: "본인이 생전에 직접 남긴 기록입니다." "사망증명서 확인과 검수를 거쳐 전달합니다." "언제든 지울 수 있습니다." "회사가 문을 닫아도 영상은 내려받아 보관할 수 있습니다."(SPEC-05 서비스 종료 대비)
3. **정서적 가치**: "목소리와 표정을 남깁니다." 후회 회피·효도·기억.
4. **투명한 가격**: 금액을 먼저, 크게. 무료 공공 서비스(e하늘) 대비 유료 명분은 AI 부가가치로.

## 5. 표현 규칙 (Do / Don't)

**Do**
- "마지막 영상 편지", "기록", "선물", "목소리를 남기다", "간직하다"
- 하이픈(-) 사용
- 구체적 예시로 풀어쓰기(원문 인용만 말고)

**Don't**
- "유언장"(법적 오인), "고인 재현"·"부활"·"되살리다"(윤리 프레임, 02 문서 Non-goals)
- 죽음 공포·불안 조성("지금 안 하면 영영...")
- em-dash(—) — 전 산출물에서 하이픈으로 (전역 규칙)
- 사후 재현을 제3자가 의뢰하는 뉘앙스(온담은 생전 본인 기록만)
- 미검증 자산을 검증된 실적처럼 포장

## 7. 시각 톤 (참고)
- 5060 가독성 우선: 큰 글씨(16px+)·큰 버튼(48px+)·고대비(WCAG AA). 어르신 UX 규칙(.claude/CLAUDE.md)이 곧 브랜드 접근성.
- 과한 장식·AI 티 나는 디자인 지양(전역 디자인 피드백과 일치): 액센트 1색+무채색 위주, 순백 배경.
- 감정 자산: 복원 전후 비교, 실제 제작 예시 영상을 최상단에.
